# deep-software-engineering
As AI continues to evolve, simply being a coder is no longer enough. I’ve decided to move beyond being just a programmer and work toward becoming a software engineer with a deeper understanding of technical concepts.

My goal is to develop a deep understanding of JavaScript, TypeScript, frameworks and libraries, software engineering concepts, and how to effectively use AI tools and get high-quality, useful results from them.

This repository is essentially my personal technical cheat sheet — a place where I document important and deep concepts in simple language, along with practical examples and clear explanations. It helps me revisit what I’ve learned and organize my technical knowledge as I continue to grow.

The goal of this repository is not to memorize concepts; it is to understand them, explain them, and be able to apply them in the real world.
